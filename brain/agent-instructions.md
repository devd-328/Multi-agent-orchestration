# Instructions for coding agents

These notes are for any coding agent that edits this repo. Runtime agents are specified in [agents.md](agents.md).

Read [RULES.md](RULES.md) before any task. That file is the only copy of the anti-hallucination and coding rules.

If a fact is not decided, write `TBD` with a one-line note in the file that owns it. Do not invent a stack or product decision. When a decision is accepted, add a record from [decisions/template.md](decisions/template.md).
